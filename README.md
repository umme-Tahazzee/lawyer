# Md. Arif Hossain – Advocate Landing Page

React + Vite + TypeScript + Tailwind CSS + shadcn/ui (Button, Input, Textarea).

    npm install
    npm run dev

- Photos: put `advocate.jpg` (and optional `gavel.jpg`) in `public/images/`. Until then a placeholder shows.
- All text/content: `src/data/content.ts`
- Colors: CSS variables in `src/index.css` (`--primary` navy, `--gold`).
- Contact form submit: handler in `src/components/Contact.tsx` (`onSubmit`) – connect your API there.
